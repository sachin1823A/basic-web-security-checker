# basic-web-security-checker# Basic Web Security Checker

A simple Python-based web vulnerability scanner designed for educational purposes.

## Features

- SQL Injection detection (basic error-based)
- Reflected XSS detection
- JSON and Text report generation
- Timestamped report files

## Usage

1. Install dependencies:
   pip install -r requirements.txt

2. Run the scanner:
   python scanner.py

3. Enter target URL with parameter.

Reports will be generated inside the `reports/` folder.

## Disclaimer

This tool is for educational and authorized testing only.
Do not use on websites without permission.
